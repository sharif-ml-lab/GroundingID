# Uncovering Grounding IDs: How External Cues Shape Multi-Modal Binding

This repository accompanies the paper *"Uncovering Grounding IDs: How External Cues Shape Multi-Modal Binding"*.  
We investigate how simple visual and textual cues induce **Grounding IDs** in large vision–language models (LVLMs), enabling robust binding of objects to partitions across modalities. Grounding IDs strengthen cross-modal attention, reduce the modality gap, and improve reasoning and hallucination mitigation in LVLMs.
